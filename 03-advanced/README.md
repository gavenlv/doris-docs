## 前置要求

### 知识要求

- 完成入门教程
- 理解三种数据模型
- 掌握基础 SQL
- 了解基本的数据库概念

### 环境要求

- Doris 集群（至少 1 FE + 3 BE）
- 内存 >= 16GB
- 磁盘 >= 100GB
- 测试数据集

## 章节详解

### 01. 高级表设计

学习表设计的核心原则和最佳实践。

**学习内容**：
- 表设计原则
- 列类型选择
- 排序键设计
- 压缩策略

**学习时间**：8 小时

### 02. 分区分桶策略

深入理解分区和分桶的设计策略。

**学习内容**：
- Range 分区设计
- List 分区设计
- 动态分区
- Hash 分桶策略
- Colocate Group

**学习时间**：8 小时

### 03. 索引深入

理解 Doris 的索引机制和优化方法。

**学习内容**：
- 前缀索引
- Zone Map 索引
- Bloom Filter 索引
- Bitmap 索引
- 倒排索引
- 索引选择策略

**学习时间**：8 小时

### 04. 查询优化

掌握查询优化的核心技巧。

**学习内容**：
- 执行计划分析
- 慢查询诊断
- 优化器提示
- Profile 分析
- 常见优化模式

**学习时间**：12 小时

### 05. Join 优化

深入理解 Join 的优化策略。

**学习内容**：
- Join 类型与选择
- Colocate Join
- Bucket Shuffle Join
- Runtime Filter
- 大表 Join 优化

**学习时间**：8 小时

### 06. 物化视图

设计和使用物化视图加速查询。

**学习内容**：
- 物化视图原理
- 物化视图设计
- 自动改写
- 维护策略
- 最佳实践

**学习时间**：6 小时

### 07. 数据建模

学习数据仓库建模方法论。

**学习内容**：
- 星型模型
- 雪花模型
- 宽表设计
- 维度建模
- 事实表设计

**学习时间**：8 小时

### 08. 性能调优

系统级性能调优技巧。

**学习内容**：
- 参数调优
- 资源管理
- 内存优化
- 并发控制
- 监控与诊断

**学习时间**：8 小时

## 练习任务

### 任务1：设计订单表

设计一个支持以下查询的订单表：
1. 按日期范围查询订单
2. 按用户查询订单
3. 按商品类别统计销售

**验证标准**：
- [ ] 分区策略合理
- [ ] 分桶策略合理
- [ ] 索引设计合理
- [ ] 查询性能达标

### 任务2：优化慢查询

给定一个慢查询，分析执行计划并优化。

**验证标准**：
- [ ] 能够分析执行计划
- [ ] 找出性能瓶颈
- [ ] 优化后性能提升

### 任务3：设计物化视图

为高频查询设计物化视图。

**验证标准**：
- [ ] 物化视图设计合理
- [ ] 查询自动使用物化视图
- [ ] 性能提升明显
