# Doris 整体架构设计

## 架构概览

Apache Doris 是一个高性能、实时的分析型数据库，采用 MPP (Massively Parallel Processing) 架构，支持标准 SQL，兼容 MySQL 协议。

## 核心组件

### 1. Frontend (FE)

FE 是 Doris 的前端节点，负责元数据管理、查询解析、查询优化和查询调度。

#### FE 角色

| 角色 | 说明 | 数量 |
|------|------|------|
| Leader | 主节点，处理写请求 | 1 |
| Follower | 从节点，可选举为 Leader | 奇数个 (1, 3, 5) |
| Observer | 观察者，不参与选举 | 任意个 |

#### FE 核心模块

```java
// 源码位置: fe/fe-core/src/main/java/org/apache/doris/

catalog/
├── Catalog.java              // 元数据中心
├── Database.java             // 数据库
├── Table.java                // 表
├── OlapTable.java            // OLAP 表
├── Partition.java            // 分区
├── Tablet.java               // 分片
└── Replica.java              // 副本

planner/
├── Planner.java              // 查询规划器
├── ScanNode.java             // 扫描节点
├── JoinNode.java             // Join 节点
├── AggregationNode.java      // 聚合节点
└── SortNode.java             // 排序节点

analysis/
├── Analyzer.java             // 语义分析器
├── StmtRewriter.java         // 语句重写

system/
├── Frontend.java             // FE 主类
├── FrontendOptions.java      // FE 配置
└── HeartbeatMgr.java         // 心跳管理
```

BE 是 Doris 的后端节点，负责数据存储和查询执行。

### 三种数据模型

| 模型 | 说明 | 适用场景 | 源码位置 |
|------|------|---------|---------|
| Duplicate Key | 明细模型，保留所有数据 | 日志、事件流 | `OlapTable` + `KeysType.DUP_KEYS` |
| Aggregate Key | 聚合模型，预聚合存储 | 报表、统计 | `OlapTable` + `KeysType.AGG_KEYS` |
| Unique Key | 唯一主键模型，支持更新 | 维度表、状态表 | `OlapTable` + `KeysType.UNIQUE_KEYS` |

## 查询处理流程

### 查询执行流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              查询处理流程                                    │
└─────────────────────────────────────────────────────────────────────────────┘

1. SQL 接收
   │
   ▼
┌─────────────────┐
│  MySQL Protocol │  接收 MySQL 协议请求
│  (9030 端口)    │
└─────────────────┘
   │
   ▼
2. SQL 解析
┌─────────────────┐
│   SQL Parser    │  解析 SQL，生成 AST
│  (Analysis)     │
└─────────────────┘
   │
   ▼
3. 语义分析
┌─────────────────┐
│   Analyzer      │  绑定元数据，类型检查
│                 │
└─────────────────┘
   │
   ▼
4. 查询重写
┌─────────────────┐
│  StmtRewriter   │  视图展开，子查询优化
│                 │
└─────────────────┘
   │
   ▼
5. 查询规划
┌─────────────────┐
│    Planner      │  生成执行计划树
│                 │
└─────────────────┘
   │
   ▼
6. 查询优化
┌─────────────────┐
│   Optimizer     │  CBO 优化，选择最优计划
│                 │
└─────────────────┘
   │
   ▼
7. 计划分片
┌─────────────────┐
│  Coordinator    │  将计划分片，分配到 BE
│                 │
└─────────────────┘
   │
   ▼
8. 分布式执行
┌─────────────────────────────────────────────────────────────┐
│                         BE 集群                              │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐                 │
│  │  BE 1   │    │  BE 2   │    │  BE 3   │                 │
│  │ Fragment│    │ Fragment│    │ Fragment│                 │
│  │ Exec 1  │←──→│ Exec 2  │←──→│ Exec 3  │                 │
│  └─────────┘    └─────────┘    └─────────┘                 │
└─────────────────────────────────────────────────────────────┘
   │
   ▼
9. 结果收集
┌─────────────────┐
│  Result Buffer  │  收集各 BE 结果
│                 │
└─────────────────┘
   │
   ▼
10. 结果返回
┌─────────────────┐
│ MySQL Protocol  │  返回给客户端
│                 │
└─────────────────┘
```

### 执行计划示例

```sql
SELECT 
    o.order_date,
    u.city,
    SUM(o.amount) as total_amount
FROM orders o
JOIN users u ON o.user_id = u.user_id
WHERE o.order_date >= '2024-01-01'
GROUP BY o.order_date, u.city
ORDER BY total_amount DESC
LIMIT 10;
```

执行计划树：

```
PLAN FRAGMENT 0
└── TOP-N (ORDER BY total_amount DESC LIMIT 10)
    └── EXCHANGE (receive from FRAGMENT 1)

PLAN FRAGMENT 1
└── AGGREGATE (GROUP BY order_date, city)
    └── HASH JOIN (o.user_id = u.user_id)
        ├── EXCHANGE (broadcast users)
        │   └── SCAN (users)
        └── SCAN (orders, partitions: p202401, p202402)
            └── PREDICATE: order_date >= '2024-01-01'
```

### 存算分离优势

| 特性 | 传统架构 | 存算分离 |
|------|---------|---------|
| 扩展性 | 计算存储绑定 | 独立扩展 |
| 成本 | 全部 SSD | 冷数据对象存储 |
| 弹性 | 扩容需迁移数据 | 秒级扩缩容 |
| 可靠性 | 多副本 | 对象存储高可靠 |

## 关键源码入口

### FE 启动入口

```java
// fe/fe-core/src/main/java/org/apache/doris/DorisFE.java
public class DorisFE {
    public static void main(String[] args) throws Exception {
        // 1. 解析配置
        Config config = new Config();
        
        // 2. 启动 FE
        Frontend frontend = new Frontend(config);
        frontend.start();
        
        // 3. 等待关闭
        frontend.join();
    }
}
```

### BE 启动入口

```cpp
// be/src/service/be_service.cpp
int main(int argc, char** argv) {
    // 1. 初始化环境
    auto exec_env = ExecEnv::GetInstance();
    exec_env->Init(config);
    
    // 2. 启动存储引擎
    StorageEngine storage_engine;
    storage_engine.start();
    
    // 3. 启动服务
    BackendService service;
    service.start();
    
    // 4. 等待关闭
    service.join();
}
```
