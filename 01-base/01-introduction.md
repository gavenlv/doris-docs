# Doris 简介

## 什么是 Apache Doris？

Apache Doris 是一个高性能、实时的分析型数据库，基于 MPP (Massively Parallel Processing) 架构，支持标准 SQL，完全兼容 MySQL 协议。

### 一句话概括

**Doris = 高性能 + 实时 + 易用 + 开源的分析型数据库**

---

### 2. 简单易用

| 特性 | 说明 |
|------|------|


## 核心特性

### 1. 多种数据模型

```
┌─────────────────────────────────────────────────────────────┐
│                    三种数据模型                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. Duplicate Key (明细模型)                                 │
│     ┌─────────────────────────────────────────────────┐     │
│     │  特点：保留所有原始数据，不做聚合                 │     │
│     │  场景：日志、事件流、原始数据存储                 │     │
│     │  示例：用户行为日志、系统日志                     │     │
│     └─────────────────────────────────────────────────┘     │
│                                                              │
│  2. Aggregate Key (聚合模型)                                 │
│     ┌─────────────────────────────────────────────────┐     │
│     │  特点：相同 Key 自动聚合，预计算                  │     │
│     │  场景：报表、统计、多维分析                       │     │
│     │  示例：销售日报、用户统计                         │     │
│     └─────────────────────────────────────────────────┘     │
│                                                              │
│  3. Unique Key (唯一主键模型)                                │
│     ┌─────────────────────────────────────────────────┐     │
│     │  特点：主键唯一，支持更新删除                     │     │
│     │  场景：维度表、状态表、需要更新的表               │     │
│     │  示例：用户表、订单表、商品表                     │     │
│     └─────────────────────────────────────────────────┘     │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2. 丰富的索引

| 索引类型 | 说明 | 适用场景 |
|---------|------|---------|
| 前缀索引 | 自动创建，快速定位 | 所有表 |
| Zone Map | 自动创建，存储 min/max | 所有列 |
| Bloom Filter | 快速判断值是否存在 | 等值查询 |
| Bitmap Index | 位图索引，低基数列 | 枚举、状态列 |
| Inverted Index | 倒排索引，全文检索 | LIKE、全文搜索 |

### 3. 灵活的分区

```sql
-- Range 分区：按时间范围
PARTITION BY RANGE(order_date) (
    PARTITION p202401 VALUES LESS THAN ('2024-02-01'),
    PARTITION p202402 VALUES LESS THAN ('2024-03-01'),
    ...
)

-- List 分区：按枚举值
PARTITION BY LIST(city) (
    PARTITION p_beijing VALUES IN ('北京'),
    PARTITION p_shanghai VALUES IN ('上海'),
    ...
)

-- 动态分区：自动创建和删除
PROPERTIES (
    "dynamic_partition.enable" = "true",
    "dynamic_partition.time_unit" = "DAY"
)
```

### 4. 物化视图

```sql
-- 创建物化视图，自动预聚合
CREATE MATERIALIZED VIEW mv_daily_sales
AS SELECT 
    order_date,
    SUM(amount) as total_amount,
    COUNT(*) as order_count
FROM orders
GROUP BY order_date;

-- 查询自动使用物化视图
SELECT order_date, SUM(amount) 
FROM orders 
GROUP BY order_date;
-- 实际查询 mv_daily_sales，速度提升 10-100 倍
```

## 架构概览

### 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        客户端层                              │
│         MySQL Client / JDBC / ODBC / BI Tools               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     Frontend (FE)                            │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  SQL 解析 → 查询优化 → 执行计划 → 任务调度          │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  元数据管理 (数据库、表、分区、副本)                 │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│  Backend (BE)   │ │  Backend (BE)   │ │  Backend (BE)   │
│  ┌───────────┐  │ │  ┌───────────┐  │ │  ┌───────────┐  │
│  │存储引擎   │  │ │  │存储引擎   │  │ │  │存储引擎   │  │
│  │查询执行   │  │ │  │查询执行   │  │ │  │查询执行   │  │
│  └───────────┘  │ │  └───────────┘  │ │  └───────────┘  │
│  ┌───────────┐  │ │  ┌───────────┐  │ │  ┌───────────┐  │
│  │ 本地存储  │  │ │  │ 本地存储  │  │ │  │ 本地存储  │  │
│  └───────────┘  │ │  └───────────┘  │ │  └───────────┘  │
└─────────────────┘ └─────────────────┘ └─────────────────┘
```

### FE (Frontend)

- **角色**：查询解析、优化、调度、元数据管理
- **高可用**：Leader + Follower + Observer
- **语言**：Java

### BE (Backend)

- **角色**：数据存储、查询执行
- **副本**：多副本保证数据可靠性
- **语言**：C++

## 快速体验

### 5 分钟快速开始

```bash
# 1. 下载 Docker 镜像
docker pull apache/doris:2.0.3

# 2. 启动集群
docker run -d --name doris-fe \
    -p 8030:8030 -p 9030:9030 \
    apache/doris:2.0.3

# 3. 连接 Doris
mysql -h 127.0.0.1 -P 9030 -u root

# 4. 创建数据库
CREATE DATABASE demo;
USE demo;

# 5. 创建表
CREATE TABLE users (
    user_id INT,
    user_name VARCHAR(50),
    age INT
)
DUPLICATE KEY(user_id)
DISTRIBUTED BY HASH(user_id) BUCKETS 10;

# 6. 插入数据
INSERT INTO users VALUES 
    (1, 'Alice', 25),
    (2, 'Bob', 30),
    (3, 'Carol', 28);

# 7. 查询数据
SELECT * FROM users;
```
