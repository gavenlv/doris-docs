## 案例详解

### 案例1：实时数仓建设

从零构建实时数仓，实现 T+0 数据分析。

**技术栈**：
- MySQL (业务库)
- Canal/Debezium (CDC)
- Kafka (消息队列)
- Flink (实时计算)
- Doris (实时数仓)

**学习内容**：
- 数仓分层设计
- 实时数据同步
- 维度表设计
- 事实表设计
- 实时指标计算

**学习时间**：20 小时

### 案例2：日志分析平台

构建日志分析平台，实现实时监控和告警。

**技术栈**：
- Filebeat/Fluentd (日志采集)
- Kafka (消息队列)
- Flink (实时处理)
- Doris (日志存储)
- Grafana (可视化)

**学习内容**：
- 日志采集方案
- 日志解析处理
- 日志存储设计
- 实时监控告警
- 日志检索分析

**学习时间**：16 小时

### 案例3：用户行为分析

构建用户行为分析系统，实现用户画像和漏斗分析。

**技术栈**：
- 埋点 SDK (数据采集)
- Kafka (消息队列)
- Flink (实时计算)
- Doris (行为存储)
- 用户画像系统

**学习内容**：
- 埋点数据采集
- 行为数据建模
- 用户画像构建
- 漏斗分析实现
- 留存分析实现

**学习时间**：16 小时

### 案例4：实时大屏

构建实时大屏，实现秒级数据刷新。

**技术栈**：
- Doris (数据存储)
- 物化视图 (预聚合)
- BI 工具 (可视化)
- WebSocket (实时推送)

**学习内容**：
- 大屏数据设计
- 物化视图优化
- 秒级刷新实现
- 高并发查询优化
- 大屏性能优化

**学习时间**：12 小时

### 案例5：数据同步方案

实现多数据源同步，构建统一数据平台。

**技术栈**：
- DataX/Flink CDC (数据同步)
- Doris (数据湖)
- 调度系统

**学习内容**：
- 多源数据同步
- 全量增量同步
- 数据质量监控
- 数据血缘管理
- 元数据管理

**学习时间**：12 小时

### 案例6：企业级部署

企业级 Doris 部署方案，包含高可用和监控。

**技术栈**：

- Grafana (可视化)

## 项目实战

### 实战1：电商实时数仓

**场景**：某电商平台需要构建实时数仓，支持实时销售分析。

**需求**：
- 订单数据实时同步
- 实时销售统计
- 实时用户分析
- 实时商品分析

**技术方案**：
```
MySQL → Canal → Kafka → Flink → Doris → BI
```

**交付物**：
- [ ] 数仓分层设计文档
- [ ] 表结构设计
- [ ] Flink ETL 代码
- [ ] Doris 建表脚本
- [ ] BI 报表

### 实战2：日志监控平台

**场景**：构建统一的日志监控平台，支持应用日志分析和告警。

**需求**：
- 多应用日志采集
- 日志实时分析
- 异常告警
- 日志检索

**技术方案**：
```
应用 → Filebeat → Kafka → Flink → Doris → Grafana
```

**交付物**：
- [ ] 日志采集配置
- [ ] 日志解析规则
- [ ] Doris 表设计
- [ ] 告警规则配置
- [ ] Grafana 仪表盘
